# Kênh đăng, kênh tham khảo và số liệu (tổ chức điền)

Tệp mẫu. Tổ chức điền rồi nạp vào kho tri thức loại **Tài liệu**. Trong hệ thống đã có màn Kênh đăng và tham số số bài mỗi ngày thì theo hệ thống.

## 1. Kênh của tổ chức
| Kênh | Đường dẫn | Mục đích | Số bài tối đa mỗi ngày | Giờ được đăng | Quy tắc riêng (ví dụ: không gửi đường dẫn) |
|---|---|---|---|---|---|
| | | | | | |

## 2. Kênh tham khảo để nghiên cứu xu hướng
Chỉ là kênh công khai. Không cần đăng nhập để xem thì ghi "công khai".
| Kênh | Nền tảng | Vì sao theo dõi | Cách xem (công khai / kết nối chính thức / tài khoản thu thập riêng) |
|---|---|---|---|
| | | | |

## 3. Tài khoản thu thập riêng
- Tổ chức có bật không: [có / không]. Mặc định không.
- Bật thì ghi: chạy trên máy nào, mạng nào; hạn mức thao tác mỗi ngày; ai chịu trách nhiệm. Không ghi mật khẩu vào tệp này.

## 4. Lấy số liệu ở đâu
| Kênh | Số liệu có | Cách lấy (công cụ hệ thống / tệp xuất / dán tay) |
|---|---|---|
| | | |
